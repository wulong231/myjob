更新日期：2026-08-30

--------------------------------------------------------
一、项目概述
--------------------------------------------------------
Bili 是一款基于 B 站开放接口的第三方视频/音频下载与播放器
（安卓版），支持搜索、在线播放、视频/音频下载、本地播放、
播放列表分类、歌词、深色模式等功能。

桌面版（PySide6）与安卓版（Kotlin + Jetpack Compose）共用
B 站接口逻辑思路，但代码相互独立。

--------------------------------------------------------
三、技术栈
--------------------------------------------------------
- Kotlin + Jetpack Compose（Material 3）
- 网络：OkHttp（带 UA/Referer/Cookie）
- 播放：Media3 ExoPlayer（视频 DASH 合并、音频前台服务）
- 图片：Coil（本地文件封面、网络封面）
- 下载合并：MediaMuxer（视频+音频流合成 MP4）
- 持久化：SharedPreferences（Settings 单例）
- 兼容：minSdk 26（Android 8.0）~ targetSdk 36（Android 16）

--------------------------------------------------------
四、核心功能与关键实现
--------------------------------------------------------
1. 搜索 / 视频详情 / 在线播放
   - BiliApi.getVideoInfo() 详情，getPlayUrl() 拿 DASH 地址
   - 播放用 ExoPlayer MergingMediaSource 合并视频+音频流
   - WBI 签名（WbiSigner）注意：isLetterOrDigit() 对中文返回
     true，须用 ASCII 判断，否则签名失败

2. 下载
   - 视频：并行下载视频流(.m4v)+音频流(.m4a)，MediaMuxer 合并 MP4
   - 音频：仅下 DASH 音频流存 M4A
   - 封面：下载后自动把 B 站封面存成同名 .jpg（供播放器显示）
   - 下载目录可改（设置页），改后重建 DownloadManager

3. 音频播放（MusicPlaybackService 前台服务）
   - 通知栏控制（播放/暂停/上一首/下一首），息屏可播
   - 播放模式：顺序 / 列表循环 / 单曲循环 / 随机（playMode 0-3）
   - 播放列表：ACTION_SET_PLAYLIST 传入 paths/titles/artists/covers
   - seek：ACTION_SEEK；停止：ACTION_STOP（播放视频前调用避免冲突）
   - 封面：MediaMetadata artworkUri + 通知大图标
   - 歌词：自动匹配（先读缓存，再按歌名搜网易云取第一条）+ 手动搜索
     + 滚动高亮 + 点击跳转 + 偏移微调

4. 视频播放器
   - 横屏自动全屏（isLandscape 检测），旋转后隐藏系统栏铺满画面
   - 播放模式：顺序/列表循环/单曲循环/随机（Settings.videoPlayMode）
   - 队列播放：vm.setVideoQueue(paths, index)，播完自动切集
   - 自绘控制条：播放/暂停 + 拖拽 seek（dragging 状态，松手才 seek）
   - 全屏时底部悬浮半透明控制条

5. 播放列表（命名分类）
   - 存储：Settings.getPlaylists() 返回 LinkedHashMap<名称, 路径列表>
     （JSON 序列化到 SharedPreferences，键 playlists_json）
   - 默认列表“我的收藏”：收藏星标 = 加入/移出该列表
   - 老版本收藏（favorites StringSet）自动迁移到“我的收藏”
   - 页面：播放列表列表页 + 详情页（播放全部音频/视频、移出、重命名、删除）
   - 加入列表：音频/视频列表项上的“+列表”按钮弹窗勾选/新建

6. 主题（深色模式）
   - Settings.themeModeState（Compose 可观察），切换立即生效
   - Theme.applySystemBarTheme() 同步状态栏/导航栏图标深浅
   - 注意：视频播放器用 WindowInsetsControllerCompat（勿用旧
     systemUiVisibility，会清掉浅色图标标志）

7. 侧边栏
   - MainActivity 的 ModalNavigationDrawer + DrawerController
   - 各主页面左上角 DrawerMenuButton 打开

--------------------------------------------------------
五、数据存储（Settings.kt 键位速查）
--------------------------------------------------------
- download_dir      下载目录名（默认 Download）
- default_quality   默认画质（100=1080P）
- theme_mode        0跟随系统 / 1浅色 / 2深色
- video_play_mode   0顺序 / 1列表循环 / 2单曲循环 / 3随机
- cookie            B 站 Cookie
- nickname          昵称（可选）
- audio_tag_<path>  音频标签 "歌名|歌手"
- lyric_<path>      歌词缓存（LRC 文本）
- playlists_json    播放列表 JSON：{"列表名":["路径",...]}
  * 默认“我的收藏”列表承接收藏；旧 favorites 键迁移后删除
- favorites（旧版） 已废弃，仅用于迁移

六、构建与打包（重要）
--------------------------------------------------------
构建命令（在 android/ 目录下）：
  .\gradlew.bat assembleRelease

产物：app/build/outputs/apk/release/app-release.apk
发布：复制并重命名到 安装包/Bili23-Android-vX.Y.Z.apk
     旧版本归档到 安装包/旧版本/

签名：keystore/bili23-release.jks
     storePassword / keyPassword = bili23123
     keyAlias = bili23
注意：签名不一致无法覆盖安装，测试时先卸载旧包。

本地工具链（勿删除）：
- android-sdk/       Android SDK（含 platform-tools/adb.exe）
- gradle-dist/       Gradle 发行版
- 依赖网络受限时自动走镜像（PyPI 同理）
